# Frontend Web Developer Internship - Week 1

## Transforming Wireframes into Static Web Pages

This project was developed as part of the Frontend Web Developer Internship.

The objective of this task was to plan a wireframe structure and transform the design concept into a functional static webpage using semantic HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Google Fonts

## Project Features

- Responsive navigation
- Hero section
- About section
- Skills section
- Projects section
- Contact section
- Footer
- Responsive layouts for desktop, tablet and mobile devices
- Hover animations
- CSS variables for consistent styling
- Semantic HTML structure

## Responsive Design

The website was designed using a mobile-first responsive approach with CSS media queries.

The layout adapts to:

- Desktop screens
- Tablet screens
- Mobile screens
- Small mobile screens

## Design Approach

The design uses a modern dark interface with a high-contrast accent color. CSS Grid and Flexbox were used to create flexible layouts while maintaining consistent spacing and alignment.

The interface was divided into reusable sections to keep the HTML and CSS organized and maintainable.

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No additional dependencies are required.
