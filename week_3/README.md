# ExploreMore – Responsive Web Design

## Week 2 Internship Task

ExploreMore is a responsive travel landing page developed from scratch as part of the Week 2 Frontend Web Developer Internship task.

## Objective

The main objective of this project is to create a webpage that adapts smoothly to different screen sizes including desktops, tablets, and smartphones.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Media Queries
- Responsive Typography
- CSS Transitions

## Key Features

- Responsive navigation bar
- Responsive hero section
- Popular destination cards
- Feature section
- Call-to-action section
- Responsive buttons
- Flexible grid layouts
- Mobile-friendly typography
- Hover animations
- Sticky navigation

## Responsive Breakpoints

### Desktop

The desktop layout uses a two-column hero section and three-column destination and feature grids.

### Tablet

At screen widths below 900px, the hero section changes to a single-column layout and content grids adjust to two columns.

### Mobile

At screen widths below 600px, cards become single-column, buttons become full-width, navigation wraps, and typography scales down.

## Testing

The website was tested using Chrome Developer Tools at different viewport sizes:

- Desktop
- Tablet
- Mobile

The layout was checked for:

- Content overflow
- Image scaling
- Text readability
- Grid responsiveness
- Navigation behavior
- Button alignment
